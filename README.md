# Unifort Abrasivos

Catálogo institucional e portal comercial com visualização 3D de produtos, para uma empresa de abrasivos e ferramentas profissionais.

## O que o projeto faz

- Apresenta a empresa e o catálogo de produtos de forma visual.
- Mostra os produtos em 3D interativo.
- Facilita o contato comercial com a empresa.

## Stack

- **React 19** + **TypeScript** + **Vite**
- **React Three Fiber** / **Three.js** (cenas 3D)
- **Framer Motion** (animações)
- **Zustand** (estado)
- **Tailwind CSS**

## Como rodar localmente

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # build de produção
```
